# Marca institucional

Colocá aquí los recursos gráficos oficiales de la Municipalidad de San Miguel de Tucumán.

Archivos esperados (nombres sugeridos):

- `logo-municipal.svg` — logo principal (preferentemente SVG por nitidez).
- `logo-municipal.png` — variante rasterizada de respaldo.
- `logo-municipal-mono.svg` — versión monocromática para fondos de color.
- `favicon.ico` / `icon.png` — íconos (opcional).

Una vez cargado el logo, se referenciará desde los componentes con la ruta
`/brand/logo-municipal.svg`. La portada (`src/app/page.tsx`) hoy usa un
placeholder tipográfico hasta que el archivo esté disponible.

> Paleta institucional definida en `src/app/globals.css`:
> azul `#0868F2`, celeste `#2FAEF2`, amarillo `#F5D600`,
> fondo `#F7F9FC`, texto `#172033`, bordes `#DCE4EE`.
